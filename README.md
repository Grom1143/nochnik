# Ночник

Помощник перед сном для Windows: настоящее ночное небо над Ростовом-на-Дону, сон по циклам, дыхание, звуки, «выгрузи голову», дневник сна и мягкий ночник с будильником-рассветом.

**Скачать:** [Ночник.exe](https://github.com/Grom1143/nochnik/releases/latest) — один файл, без установки и без интернета. Нужна Windows 10 или 11 (движок WebView2 в них уже есть).

## Что внутри

- **Небо в реальном времени.** 22 тысячи звёзд до 7,5m, 70 созвездий, Млечный Путь, Луна в правильной фазе (текстура NASA LRO) и планеты. Положения считаются по формулам и сверены с JPL Horizons.
- **Режим «Небо»** (клавиша N): интерфейс исчезает, небо можно тянуть, приближать колесом или щипком до ×13, T ускоряет время в 600 раз.
- **Сон по циклам:** когда лечь, чтобы встать в конце цикла; подъём по дням недели.
- **Дыхание** 4-7-8, «квадрат», резонанс и сканирование тела.
- **Звуки**, синтезированные на лету: дождь, море, ветер, костёр, сверчки, птицы, кот, бурый шум. Есть таймер.
- **Ночник:** тёплый свет, рассвет-будильник, «ещё 10 минут», сам гаснет через 15/30/60 минут и бережёт батарею.
- **Дневник сна** и **Эфир** — инструмент света и звука.

Приложение открывается на весь экран. Чтобы выйти, подведи мышь к правому верхнему углу и нажми ×. F11 переключает окно и полный экран.

## Как устроено

- `nochnik.html` — всё приложение одной страницей (Canvas 2D, Web Audio, без библиотек). `Ночник.html` — та же страница для запуска из браузера.
- `инструменты/Ночник.cs` — окно Windows на WebView2. Страница, шрифты и библиотеки зашиты внутрь exe. Сборка: `python инструменты/собрать_exe.py` (компилятор C# уже есть в Windows).
- `инструменты/данные_неба.py`, `текстура_луны.py`, `шрифты.py` — подготовка данных неба, Луны и шрифтов.
- `тесты/regress.py` — 17 сценариев в невидимом Edge.
- `Как устроен Ночник.md` — подробный учебный разбор с заданиями.
